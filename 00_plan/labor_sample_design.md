# 채용공고 자동 수집 + 수동 검수 표본 설계

## 목적

3장 AI 인력 시장 분석에서 공식 통계가 포착하지 못하는 신흥 직무와 요구 스킬셋을 보완하기 위해 2023년 1월~2026년 5월 범위의 채용공고를 자동 수집한 뒤, 작성자가 수동 검수해 50~100건 표본으로 확정한다.

## 수집 원칙

- 자동 수집은 학술 목적 표본 구축에 한정한다.
- 수집 전 robots.txt·서비스 약관·공개 API/다운로드 허용 범위를 확인한다.
- 로그인 우회, 캡차 우회, 유료벽 우회, 비공개 API 접근은 금지한다.
- 요청 간격을 두고 저속으로 수집하며, 서버에 부담을 주는 대량 요청은 하지 않는다.
- 자동 수집 결과는 작성자가 수동 검수해 최종 표본에 포함한다.
- 공고 수는 실제 채용 수가 아니므로 본문에서는 “채용공고 표본”으로만 표현한다.
- 동일 기업·동일 직무·동일 내용의 재게시 공고는 중복으로 보고 1건만 남긴다.
- 접근일과 원문 URL을 반드시 남긴다.
- 사라질 수 있는 웹 공고는 `01_research/raw/`에 PDF 또는 스크린샷으로 저장한다.
- 수집 조건과 한계는 `02_data/source_log.csv`에 기록한다.

## 표본 할당 초안

| 구분 | 목표 표본 | 비고 |
|---|---:|---|
| 데이터 사이언티스트 | 10~15 | 분석·모델링 중심 |
| ML 엔지니어 | 10~15 | 모델 개발·서빙 포함 |
| AI/딥러닝 엔지니어 | 10~15 | 비전·NLP·추천 포함 |
| MLOps·플랫폼 엔지니어 | 5~10 | 인프라·배포 중심 |
| 응용 AI 개발자(LLM 응용) | 10~15 | RAG·에이전트·API 활용 |
| 프롬프트 엔지니어/AI 오퍼레이터 | 5~10 | 별도 직군 여부 확인 |
| AI 리서처 | 5~10 | 석박사·논문 요건 확인 |

## 직무 분류 우선순위

직무명이 모호하면 원문 업무내용을 기준으로 판단한다.

1. 논문 작성, 신규 알고리즘 연구, 석박사 우대/필수 비중이 크면 `AI 리서처`
2. 모델 배포·운영·인프라가 핵심이면 `MLOps·플랫폼 엔지니어`
3. LLM API, RAG, 챗봇, 에이전트, AI 기능 제품화가 핵심이면 `응용 AI 개발자(LLM 응용)`
4. 딥러닝 모델 자체 개발이 핵심이면 `AI/딥러닝 엔지니어`
5. 일반 ML 모델 개발과 서비스 적용이 핵심이면 `ML 엔지니어`
6. 분석, 지표, 실험, 예측, 비즈니스 의사결정이 핵심이면 `데이터 사이언티스트`
7. 프롬프트, 생성 결과 검수, AI 도구 운영 중심이면 `프롬프트 엔지니어/AI 오퍼레이터`

## 포함·제외 기준

포함:

- 직무명에 AI, ML, 머신러닝, 딥러닝, 데이터 사이언스, LLM, MLOps, NLP, Vision, 추천, 생성형 AI 등이 포함된 공고.
- 업무내용에 AI/ML 모델 개발, LLM 응용, 모델 배포, 데이터 기반 예측·실험, AI 서비스 개발이 명시된 공고.
- Python, PyTorch, TensorFlow, scikit-learn, LangChain, vector DB, MLflow 등 AI 관련 기술이 핵심 요건인 공고.

제외:

- 일반 개발 공고에서 AI가 단순 우대사항으로만 언급된 경우.
- 데이터 입력, 단순 라벨링, 일반 사무직 등 AI 직무로 보기 어려운 경우.
- 교육 광고, 부트캠프 모집, 프리랜서 홍보성 게시물.
- 회사명, 직무명, 업무내용, URL 등 핵심 정보가 불충분한 공고.
- robots.txt·서비스 약관에서 자동 수집이 금지된 공고.
- 로그인·캡차·유료벽·비공개 API 우회로 얻은 공고.
- 수집 조건과 접근일 로그가 없는 자동 수집 공고.

## 플랫폼 편향 메모

- 사람인·잡코리아는 중소·중견기업, 비IT 기업의 AI 도입 수요가 상대적으로 더 많이 보일 수 있다.
- 원티드·점핏은 IT 스타트업, 개발자 채용, 경력직 공고가 과대표집될 수 있다.
- LinkedIn과 회사 채용페이지는 글로벌 기업, 대기업, 연구직, 영어 기반 공고가 상대적으로 많이 포착될 수 있다.
- 플랫폼별 검색 알고리즘과 유료 노출 여부가 표본에 영향을 준다.

## 권장 검색어

`AI 엔지니어`, `머신러닝 엔지니어`, `딥러닝 엔지니어`, `데이터 사이언티스트`, `MLOps`, `LLM`, `생성형 AI`, `RAG`, `NLP`, `Computer Vision`, `추천시스템`, `AI Researcher`, `Prompt Engineer`

## 파일럿 실행 절차

1. 후보 URL 목록을 CSV로 작성한다.
2. 각 후보에 대해 `robots_terms_checked=yes` 여부와 로그인·캡차·유료벽·비공개 API 필요 여부를 기록한다.
3. `python3 02_data/scripts/job_posting_collection_dry_run.py --targets 02_data/job_posting_collection_targets_example.csv --write`로 표본 CSV와 출처 로그 CSV에 들어갈 행을 검증한다.
4. dry-run 결과를 수동 검수한 뒤 최종 편입 시 `02_data/raw/job_posting_sample.csv`와 `02_data/source_log.csv`에 반영한다.
5. 실제 네트워크 접근과 파일 저장은 별도 후속 단계로 분리한다.

## 본문 반영 한계

- 표본은 대표통계가 아니라 탐색적 보조자료다.
- 플랫폼별 이용 기업군 편향을 명시한다.
- 공고 수와 실제 채용 수를 구분한다.
- 자동 수집 결과는 원자료가 아니라 수집 조건에 의해 구성된 표본임을 명시한다.
