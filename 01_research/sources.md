# 1차·보조 자료 인용 DB

> 사용 규칙
> 1. 모든 자료는 본문 인용 전 이 파일에 먼저 기록한다.
> 2. 본문에는 원문 그대로 복사하지 않고, 작성자가 요약·재구성해 반영한다.
> 3. 표준 출처 양식: `[출처: 기관명/저자, 「자료명」, 발행연도, 페이지(있으면), URL, 접근일 YYYY-MM-DD]`
> 4. 페이지가 필요한 책·PDF·논문은 본문 작성 전 원문 페이지를 재확인한다.
> 5. 자료등급을 확인해 사실 근거, 해석 근거, 사례 근거를 구분해 사용한다.

## 자주 빠지는 함정

1. **원문 페이지 누락**: 책·PDF·논문 직접 인용 전 페이지 확인.
2. **재인용**: 연구보고서가 인용한 원자료는 원자료까지 추적.
3. **사업 공고의 과대해석**: 공고는 정책 의도 자료이지 성과 자료가 아니다.
4. **기업 홍보자료의 과대해석**: 도입 사실과 성능·효과를 분리.
5. **공고 수와 채용 수 혼동**: 채용 플랫폼 자료를 쓸 경우 자동 수집 조건, 수동 검수 절차, 표본 한계를 명시.
