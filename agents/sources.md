# 1차 자료 인용 DB

> **사용 규칙**
> 1. 모든 자료를 본문 인용 전 이 파일에 먼저 기록한다.
> 2. 각 자료마다 (1) 서지정보 (2) 핵심 데이터·인용 후보 문장 (3) 본문 활용 위치 메모를 함께 남긴다.
> 3. 출처 양식: `[출처: 기관명, 「자료명」, 발행연도, 페이지, URL, 접근일 YYYY-MM-DD]`
> 4. 인용 후보 문장은 **원문 그대로**가 아니라 **요약·재구성**한 형태로 기록 (Turnitin 회피 + 표절 방지)

- **발행기관**: 소프트웨어정책연구소(SPRi)
- **저자**: SPRi 산업·정책연구실
- **발행연도**: 2024
- **자료 종류**: 정부산하 연구기관 보고서
- **URL**: https://spri.kr/posts/view/(실제 URL 채우기)
- **접근일**: 2026-05-12
- **표준 인용 양식**:
  ```
  [출처: 소프트웨어정책연구소(SPRi), 「2024 인공지능산업 실태조사」, 2024, p.XX, https://spri.kr/..., 접근일 2026-05-12]
  ```

#### 핵심 데이터·인용 후보

1. [p.XX] 한국 AI 산업 매출 규모 (재구성)
2. [p.XX] AI 기업 수, 종사자 수 (재구성)

## 자주 빠지는 함정

1. **본문에서 직접 검색**: 본문 쓰다가 자료 검색하면 컨텍스트 스위치로 시간 낭비. → 자료는 Phase 2에 몰아서 등록.
2. **원문 그대로 복사**: 인용 후보를 원문 그대로 복사하면 Turnitin·KCI에서 잡힘. → 등록 시점부터 요약·재구성.
3. **URL만 기록**: 접근일·페이지 누락. → 등록 시점에 모두 채움.
4. **재인용**: A 보고서가 B 자료를 인용한 것을 A 출처로 적음. → B 원문을 찾아 직접 인용.
5. **접근 불가 자료**: 유료 DB의 abstract만 보고 인용. → 본문을 본 자료만 인용.
